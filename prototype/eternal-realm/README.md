# 永夜：新境界 — 獨立遊戲原型

這是與現有永夜 v198 分開的全新可玩原型，位於獨立分支 `prototype/eternal-realm-alpha` 的 `prototype/eternal-realm/` 目錄；不修改 v198 原有遊戲程式。

## 已實作的原型功能
- Canvas 斜角 2D 風格場景與程序繪製地形、樹木、人物、怪物。
- WASD／方向鍵、點擊地面移動、手機虛擬搖桿。
- 五職業選擇、角色 HP/MP/EXP HUD。
- 點擊選取怪物、近戰攻擊、火焰箭、治癒術、傷害數字與簡單動畫。
- 怪物追擊與反擊、死亡、經驗升級、金幣和簡易掉落。
- 三張原型地圖切換、背包彈窗、手機響應式版面。
- 以單一 HTML/Canvas 控制遊戲迴圈，限制裝置像素比最多 2，避免過度增加繪圖負擔。

## 尚未實作／不可視為完成
- 多人連線、帳號登入、伺服器權威戰鬥、資料庫存檔。
- 真正的精靈圖／原創美術素材、尋路網格、正式碰撞地形。
- 完整裝備數值、技能學習、掉落表、音效、任務與 GM 後台。
- 正式部署與跨裝置實機回歸測試。

## 本機試玩
直接用現代瀏覽器開啟 `index.html` 即可遊玩；此原型不需建置工具或外部套件。
