# Private polymorph assets

The game uses Moon Rabbit appearances while `lib/game/lineage-global-polymorph.json` is empty. Enable only entries with an independently verified mapping and permission to reuse the specific sheets in this project. Manifest keys are Starry Idle form IDs. Entries contain `spriteId`, `actionTableId` and directional actions. Frame coordinates use `[sheet, cell, columns]` in a 96 × 112 pixel atlas. Use `skill` for cast.

Set the GitHub Actions repository variable `PRIVATE_POLYMORPH_BUCKET` to the name of the dedicated private R2 bucket on the test Cloudflare account. The test Worker build adds it as `PRIVATE_POLYMORPH` alongside the existing `BUCKET`. Set the Worker secret `PRIVATE_POLYMORPH_OWNER` to the intended account's `game_accounts.owner` value. Leave the bucket's r2.dev access and custom domains disabled. Preserve the existing `BUCKET` binding. Place only approved sheets at `lineage-global/polymorph/<spriteId>/<sheet>.webp` in the dedicated bucket. Keep these sheets outside the public directory and build output.

The same-origin asset route verifies a current game session for the configured owner before reading a listed object from the dedicated binding. Verify owner GET and HEAD, then repeat in a signed-out browser and as another account. Removal of the private binding, owner secret, or manifest entries reverts the affected visuals to Moon Rabbit. Missing directions, clips or images also use the Moon Rabbit renderer. These visual mappings do not change the saved form ID or gameplay bonuses.
