# 角色登入中斷：修正範圍與驗證

日期：2026-10-25。

使用者回報可載入角色選單，選角進入時持續出現連線中斷。
已確認測試站部署 8cf3f7d 成功，並非尚未部署。尚未取得原帳號的失敗回應，不能宣稱已定位其線上根因。

本次修正三項可確認的風險：

1. 選角色原本沿用一般操作的 8 秒期限，現使用 30 秒；選角仍只送一次，不自動重送可能已提交的操作。
2. POST 原本忽略同步游標，反覆傳輸角色已載入的設定。現 GET/POST 都可使用游標，伺服器仍核對角色與完整 settingsKey；同角色同版本省略設定，換角或版本變更仍完整傳送。
3. 先前離線改寫讓線上 advance 的 budgetMs 失效。現恢復每完成一個遊戲秒後檢查運算時間，保存 mode=online 的接續游標；下一次精確補完，不把在線戰鬥轉成固定離線收益，不重複給獎。這是逐完整 tick 的時間預算，不是作業系統層的 CPU 硬上限。

操作逾時保留原錯誤原因，方便區分逾時、非 JSON HTTP 回應與其他網路錯誤。

驗證：新增選角 30 秒期限與 POST 游標測試；在線補算以零預算強制分批，經過存檔／讀檔後的角色狀態及收益與一次計算一致。
本機實際 Worker HTTP 測試涵蓋註冊、登入、創角、選角、登出重登、離線收益及連續五次選角，並檢查同版本不重送設定。
需另外驗證原帳號在線上測試站的結果；本機測試不代表已重現或修復使用者所見的線上錯誤。
