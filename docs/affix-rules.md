# 碧恩賦予與泰坦皮帶暗黑詞條

依使用者 2026-10-06 提供的完整規則實裝。尚未宣稱取得原站伺服器或涵蓋未提供的其他裝備詞條。

## 碧恩服務

村莊 → 象牙塔 → 碧恩 → 裝備賦予／解除詛咒。伺服器要求 `town_ivory_tower` 與 `npc_bian`，預覽可以在背包工坊查看，但賦予與解除詛咒只能在該所在地執行。

武器、防具、飾品分別消耗 `new_item_bless_wpn`、`new_item_bless_arm`、`new_item_bless_acc` 一張。解除詛咒消耗 `new_item_uncurse` 一張。材料必須未鎖定、無任何賦予／暗黑／舊版詞綴、未強化；明確指定錯誤材料不會自動改扣別種卷軸。所有限制通過才扣料。

三系各 1/3。祝福／詛咒系內各 1/2；遠古／永恆／不朽／太初系內各 1/4；屬性第一／二／三階系內 60%／30%／10%，各階四屬性均勻。顯示百分比有四捨五入，計算不使用加總為 99.99% 的字串。

相同詞條移除，同系不同詞條替換，其他系與暗黑詞條不動。詛咒阻止卸下、被其他裝備替換、被雙手武器間接卸下盾牌及再次賦予；先解除詛咒。解咒只移除詛咒槽。

## 能力與戰鬥

完整數值表位於 `lib/game/affix-rules.ts`。AC 使用有正負號的實際數值（防禦提升 1 = AC -1）。SP 與最大 MP 分開：SP 加入本版原有魔法基礎傷害，再經 MR／屬性抗性計算；未改造為未提供的原站魔法公式。

武器強化每 +1 追加相應近／遠傷害与命中。額外傷害在爆擊／双倍倍率之後加入，屬性固定與對剋傷害同樣最後加入；三重矢每支各算一次固定傷害。屬性武器基礎 +1／3／5、對剋再 +6／9／12；防具／飾品該屬性抗性與 MR +1／2／3。

## 暗黑詞條

僅新增「泰坦皮帶」掉落時生成，包含原本怪物掉落、GM 自訂怪物掉落、世界王掉落。同款每件獨立擲。0／1／2 條為 50%／45%／5%；灰／藍／暗金為 70%／25%／5%。13 項詞條均勻抽取，雙詞條不放回抽样；各品階數值均勻取整數。無詞條可堆疊，帶詞條以 UUID 實例保存。

購買、GM 直接送裝、既有泰坦皮帶不追溯抽取掉落詞條。原始掉落機率與其他怪物設定未改動。暗黑詞條無重洗操作，賦予與強化均保留暗黑詞條（衝裝消失時該件一起消失）。能力於穿戴時生效，背包、倉庫與裝備欄使用同一實例。

## 相容與保護

既有本版單項自訂詞綴保留效果，標示「舊版」，不再抽取；與新三系分開兼容以避免更新刪除原裝備能力。新掉落暗黑能力與任一賦予能力都受到自動賣出、一鍵販售和 NPC 材料保護。手動明確出售仍可處理未穿戴物品。

原有 50,000 金幣特別訂購卷軸保留並標示本版，並非聲稱同步克里斯特的原站兌換配方；解除詛咒卷軸取得沿用現有道具管道及 GM 贈送，不新增臆測售價。
