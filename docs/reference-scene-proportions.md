# 手機直式戰鬥比例

依使用者提供 ScreenRecording_10-18-2026 22-16-36_1.mp4 參考：一般戰鬥背景約 512×330。一般狩獵場與村莊以相同長寬比呈現；多人數場景 512×400。人物顯示框寬度為場景 32%，沿用先前死亡騎士／黑暗精靈的原像素與腳底校正，實際人物約為場景寬的 16%。一般怪物顯示框為場景寬 23%，保留不同素材的本來體型與留白；不把每種怪物強制放大成相同身高。

人物位置 x20%、y55%；普通三隻怪位置為 (68,70)、(82,43)、(84,83)。地圖名稱／返回／開始停止按鈕置於地圖上方空間，HP/MP 保留左上，避免額外控制列把地圖拉高。比例由實際場景寬度決定，適應不同 iPhone。

世界王保留 1.5 倍放大與原始四龍圖層；為血條、大型怪物留額外高度，單王 512×380、擁擠場景 512×470。橫式介面保留既有配置。本次是比例比照，不是複製影片的完整 UI、地圖內容或角色素材。

驗證既有 sprite layout、combat smoothness、dragon381 顯示與邊界測試及正式建置。未做 Safari 實機畫面驗證。
