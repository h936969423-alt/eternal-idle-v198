# 選角 HTTP 503 根因與修復

2026-10-25，透過測試 Worker 的既有 Observability 紀錄確認 /api/game GET/POST 發生 exceededCpu（約 2000ms 後 503），另有 exceededMemory。

根因：7705a27 的離線結算把相對戰鬥計時 c.atkClock、c.mobClock、Encounter.clock、magicClocks 設成 now。這些欄位單位為累積秒數，不是 Unix 毫秒。居民怪物仍留在 arena 時，下一次 second() 的 gap-clock 變成極大負值，迴圈試圖建立數十億至數千億筆攻擊／魔法事件，耗盡 CPU 或記憶體。首次空 arena 的測試未涵蓋此情境，因此先前本機測試未發現。

修正：

- 離線結算將相對計時歸零，絕對時間欄位維持原用途。
- 讀取時自動修復已寫入存檔的非有限、負數及時間戳型巨大相對計時；角色、裝備、金幣與經驗不刪除。
- 產生怪物攻擊／魔法事件前再次依實際週期限制累積秒數，防止建立無界歷史事件。
- 修復也涵蓋其他角色與已保存世界王房間，不需玩家刪角或重建帳號。

新增回歸涵蓋：已有存活怪物的離線→上線、已寫入 1792910000000 的角色／怪物／魔法時鐘、存檔讀取自動修復、收益與背包保留、事件數有界。
HTTP 測試另直接在本機 D1 建立同型受影響存檔，再透過真正 POST 選角確認修復；不使用玩家帳密或遠端資料庫改寫。

hotfix-v198-clock-20261025 專用分支的修復部署使用既有隔離測試 D1/R2 與部署流程，加入本次回歸門檻。沒有提高付費方案或關閉安全檢查。
