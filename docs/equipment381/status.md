# 3.81 裝備替換狀態

本次依使用者 2026-10-17「替換」指示，啟用已驗證數值與背包圖示。完整同版能力與素材就緒狀態仍為 false，未偽造驗證結果。

- 遊戲裝備庫、圖鑑及 GM 選單改用 2,248 件阿胖 3.81 原始裝備，移除 1,281 筆舊裝備定義。
- 1,046 種無損背包圖示完整，原始欄位、能力組、魔法與特殊程式可在單件詳情查看。
- 82 套裝數值、職業／等級限制、一般／祝福強化、原始強化成長已接入；新增六個符文／護符欄位。
- 既有掉落只對應同名的 793 筆舊編號，其餘舊裝備引用移除；GM 自訂掉落讀取時同樣轉換及過濾。不是把原 3.81 全伺服器掉落表一併移植。
- 有既有同名價格的裝備沿用永夜價格；未取得來源價格的裝備不虛構販售價格，可由 GM 發放。
- 每個帳號第一次由遊戲 API 或 GM 發放接觸存檔時，原子備份完整原 payload 與 revision，清除背包、倉庫、穿戴、寵物穿戴中的舊裝備及相關強化／詞條引用。
- 等級、經驗、金幣、技能、娃娃、寵物及歷史獎勵保留；狩獵暫停以便重新穿戴。版本標記確保只清除一次。
- 備份表 equipment_catalog_backups 為伺服器私有資料，不向前端提供原存檔。備份或寫入失敗會原子回滾，確認衝突則從最新存檔重試。
- 受託替換不等於完整能力移植：特殊 Java 能力、武器魔法、DIY／暗黑／部分條件效果尚未接入，不會套用舊永夜效果冒充 3.81。
- 缺失地面 SPR、部分 list.spr 動作定義與原始引用問題仍詳列 missing-assets.md。

## 回復方式

先切回替換前的第 110 版（來源 9449ead71f298132f65116bf4004a90e71e1fad8），再由授權維護流程取對應帳號 apang381-equipment-v1 備份，以目前 revision 比對後還原 game_saves.payload；不可在仍啟用新裝備庫時直接回灌舊存檔。尚未執行任何回復。

## 驗證

逐件原始欄位與圖示對照、全部裝備可穿戴／衍生值有限、八職業初始武器、大小怪傷害骰、AC 與成長、強化邊界、移除舊掉落、備份不可變、CAS 衝突與只執行一次均有程式測試。手機瀏覽器操作未實測。
