# 日出寵物系統移植至永夜

參考：pp771007/idle-lineage-class，固定版本 5f00f4a86389aaa7309c24d7a7c1ab060c47b500，主要為 js/22-pets.js。保存方式使用永夜現有帳號存檔與 D1，不另用瀏覽器 localStorage。

## 已接入

- 既有43種寵物能力與八方向動畫，改為唯一個體UID；同種可以持有多隻。
- 帳號共用32隻保管，最多4隻出戰，依每隻6／12／15／20魅力加總。其他角色出戰中的個體不能操作。
- 舊存檔自動保留等級、裝備、死亡狀態與經驗進度；舊資料超過32隻時保留全部，停止新增，不刪除舊寵物。
- 七種誘捕餌效果600秒，擊敗對應怪物後收服；四種蛋孵化；滿倉不扣蛋、不消耗誘捕效果。
- 每隻活著的出戰寵物各得完整戰鬥經驗。需求為永夜人物經驗公式的十分之一，等級不超過人物與100級；到上限不囤積經驗。
- 每隻從自己位置選最近怪物，保留人物原目標；無怪時遊走。沿用永夜受擊選擇，套入日出寵物種類權重。
- 依個體設定補血比例、暱稱與鎖定；裝備獨立，卸下時保存強化與附加能力。
- 新增12件來源寵物裝備；角色不能誤穿寵物裝備。用品與裝備由寵物面板村莊商店取得。
- 30級可進化：保留個體與裝備、重置1級、最大生命魔力各半，進化後收回以重新檢查魅力。
- 野外倒下5秒後可自動消耗未鎖定復活卷軸，半血滿魔復活；已學返生術可立即消耗魔力復活；村莊免費全復原。
- 寵物持續傷害帶個體來源，魔法選擇先檢查魔力，避免選到付不起的技能而停滯。

## 適配界線

用品、蛋與果實售價為永夜設定；12件裝備數值取來源。43種均保留定義，並非全部都有新取得管道；本次只開已確認的誘捕、四種蛋及進化途徑。

未替換永夜整體怪物仇恨系統為日出完整動態仇恨公式。離線狩獵沿用永夜算術結算，不模擬逐隻寵物移動、誘捕與逐刀戰鬥。召喚獸是獨立系統，本次未改為寵物。

## 驗證

scripts/test-sunrise-pets.cjs 驗證實際遊戲模組的21項流程，結果見 sunrise-pet-verification.json。另執行既有技能與存檔相容性測試；部署流程包含完整 TypeScript 檢查與 Worker 建置。手機介面以320與390像素測試；本機介面測試替代寵物預覽圖，不代表逐一播放43套動畫，動畫資源以現有圖集設定核對。
