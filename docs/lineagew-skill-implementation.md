# 五職業技能執行與驗證（2026-10-27）

範圍為永夜單機的 231 筆已移植技能；以目前明列的永夜適配規則驗證，不等於天堂 W 伺服器的完整複製。

## 本次修正

- 新技能暈眩／失明判定讀取對應命中加成；持續控制抗性加入暈眩、冰凍、石化、睡眠、束縛、沉默、緩速及失明的抵抗率，總機率上限 100%。此為永夜規則。
- 能力的防禦／迴避貫穿不再被限定在 W 武器。
- 被動主能力套用後，重新計算智力魔法表的差額；魔法轉近戰以最終魔法能力計算，避免重複加算。
- 負重依背包（含已裝備品、不重複計數）物品重量計算，不含倉庫；未知重量為 1、明列重量為 0 仍為 0。容量為 1500＋力量×15＋體質×15＋負重能力。超過容量時，角色的自然回復減半；達兩倍容量時停止角色自然回復。娃娃回復、藥水、技能治療保持各自機制。超重使移動／重新遭遇等待增加，最多增加 50%。不刪除道具、不丟棄掉落物。這是永夜適配，不是新增背包格數或聲稱還原原版負重公式。
- 無所遁形術對目前存活敵人解除隱匿／偽裝狀態，並附加限時揭露；隱匿狀態有實際普通攻擊命中限制。一般怪物的物理攻擊也尊重玩家隱身；具有偵測能力者例外。
- 隊伍技能對當前存活寵物與召喚物分享增益；包含攻擊、命中、防禦、回復、生命上限、減傷與獨立消耗的護盾。到期恢復原上限，開關關閉同步解除。未新增真人隊伍／血盟／PvP。
- 所有物理技能使用攻擊動作，其餘主動技能使用施法動作。
- 保留既有同名／舊名特效；63 招原先使用通用備援的技能改用可解碼的永夜向量動畫，依類型、屬性、品質與技能編號區分。75 招沒有既有聲音的技能改用依類型及元素生成的短音效。不是天堂 W 原版素材；未增添對專屬原版動畫的主張。

## 驗證

`node scripts/test-lineagew-complete.cjs` 執行正式引擎與正式計算模組，涵蓋 231 筆技能，另有專門缺口回歸案例，合計 241 項檢查。逐招檢查：被動改變能力或強化基礎倍率；主動實際扣血、施加狀態、回復、解除、重建遭遇或輸出偵察資料；單體不波及其他目標；資源與冷卻；開關可關閉；特效設定與動作類型。測試採受控高資源角色以隔離技能執行，並非正常養成可達到所有技能消耗的證明。

另外保留原有 14 項技能整合檢查與部署既有戰鬥／同步／聲音回歸。新增 63 招動畫共 1,134 個影格已在瀏覽器解碼確認。圖示與原有特效不因此視為全部逐招實機驗收。

逐項結果在 `docs/lineagew-skill-verification.json`。CI 會重新執行並產生結果；不以顯示名稱或有事件當成完整行為驗證。

## 驗收界線

這輪驗證是永夜單機適配版本。來源未公開的傷害公式與機率仍採永夜規則；原始天堂 W 動畫／聲音、真人範圍隊伍／PvP、真實導航位移並未新增。牽引、衝刺等目前仍用現有控制／攻擊適配，不聲稱有導航位移。獨立狀態圖示仍採技能圖示。手機長時間遊玩、所有動畫在真實戰鬥中的對位、iPhone 靜音／背景恢復及實際聲音仍需實機驗收，不能以本輪自動測試取代。
