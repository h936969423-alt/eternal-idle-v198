## 存檔與舊裝

依前版顯示品質及職業、部位篩選，下架 1713 個舊 ID，完整原始定義保存在 `lineagew-retired.json`。高於稀有及範圍外物品的定義保持原樣。

151 個舊 ID 存在唯一同名、同部位、相容職業和武器種類對應。每個舊 key 都轉成獨立且可重現的新實例 key，保留背包／倉庫數量、強化、穿戴及鎖定；不延續自動販售，以免新裝意外出售。有詞綴或對應不明的持有物移到角色「舊裝保留」，保留原 key、數量、強化、原穿戴、鎖定、詞綴及暗黑詞綴。沒有販售、刪除或材料消耗動作。

帳號第一次經遊戲或 GM 贈送寫入時，原始存檔字串與 CAS 更新同一個 D1 atomic batch 提交，備份存入 `equipment_catalog_backups`，版本鍵為 `lineagew-nar-v1`。CAS 失敗先重讀，沒有成功更新就不寫備份。原 3.81 遷移仍先執行。遷移冪等，戰鬥暫停，讓玩家確認穿戴再恢復狩獵。

已翻譯公開掉落、Boss 掉落、GM 自訂掉落／混合池、商人自訂庫存、圖鑑及 GM 贈送清單。無可靠對應的舊掉落不會以別種裝備冒充。材料已下架的配方不顯示，避免免費製作。

## 能力邊界

來源強化列是相對 +0 的追加值，不逐階累加，也不重複使用永夜通用 +N 命中、傷害、防禦。超過來源最高 +12 的強化依個別已列最高階封頂；未列強化表則停用玩家強化。原神話試作 +0～+7 及技能動畫保持原規則。

已接入現有能力欄位、命中、大小型傷害範圍、裝備防禦、暴擊／雙倍機率、HP/MP 上限與恢復、不死族追加傷害等。原剩餘 50 件能力已依下方 effects-v1 接入，來源標籤與逐階機率保留在 appliedEffects。PVP 命中已接入玩家目標條件判定，目前沒有玩家對戰模式，因此打怪不觸發；負重獎勵只保留數值，尚無負重限制機制。

普通／高級／稀有商店預設價為 500／10000／50000 金幣，出售 25%；價格、掉落分配、衝裝機率是永夜規則，並非天堂 W 原版資料。暫不增加額外詞綴。

## 重現與驗證

`python scripts/crawl-lineagew-equipment.py /tmp/lw-catalog` 讀公開來源並快取 HTML。

`python scripts/import-lineagew-equipment.py /tmp/lw-catalog` 從固定基準重建清單、舊裝對照和圖示。圖片下載完整後才啟用 activation，任何缺圖或清單數量不符都禁止存檔遷移。

`node scripts/test-lineagew-equipment.cjs` 核對全目錄及所有強化階、舊定義精確保存、實例衝突、詞綴／鎖定／倉庫、CAS 競態、冪等、React 詳情及保留頁。神話、灰綠藍外觀、混合掉落、三重矢、自動施法與魔法公式另做回歸測試。
