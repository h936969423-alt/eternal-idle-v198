# 永夜：魔法動畫與技能書移植

來源：pp771007/idle-lineage-class，固定提交 `5f00f4a86389aaa7309c24d7a7c1ab060c47b500`。
參照 `js/09-vfx-render.js` 的 SPELL_FX / SELF_FX，以及 `js/08-items-equip.js` 的技能書使用分支。
這是秋玥作品的衍生版，並非阿肥即時版的伺服器原碼。

## 實作

- 導入125 組特效設定，含黑暗妖精、異常、治癒、增益及攻擊；連同既有特效與頭盔別名共 134 個名稱。
- 2197 張來源 PNG，共 8260256 bytes。建置從固定提交還原，逐檔驗證 Git blob SHA-1 與大小；新檔放 `assets/fx-import`，不覆寫既有 R2 素材及其版本索引。
- 保留四／八方向、陰影、究極光裂術的三層序列。一次性動畫由 rAF 依經過時間選幀，背景頁面停止播放；沒有移植來源為每個特效開啟 interval 的做法。
- 魔法投射物依畫面距離決定 140～380ms 飛行，發射時固定截止時間；扣血、跳字、受擊、死亡後掉落及下一隻生成皆等同一個命中時刻。之後的網路封包不搬動已飛出的投射物。
- 保留永夜既有伺服器技能等級、職業、屬性、傷害、MP、吉倫價格及三重矢規則，不以來源遊戲的資料庫取代它們。
- 技能書沿用背包使用／技能頁學習流程；補上精確消耗使用者選取的那一疊書。偽造書與技能對應、鎖定書、已學技能都不消耗道具。

## 驗證

`scripts/test-magic-migration.cjs` 驗證每張檔案雜湊、方向／陰影／多層、播放結束、140/380ms 命中及掉落順序、指定技能書消耗與重複／鎖定／偽造防護。
另執行吉倫學習、三重矢同步、戰鬥 gate、離線收益與 GM 權限測試及完整建置。
原帳號的手機畫面仍需實際登入驗收；自動測試不代表已登入玩家帳號操作。
