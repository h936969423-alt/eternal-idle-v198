# 阿肥怪物與世界王掉落合併（2026-10-29）

以 GitHub `fe12e7ff6e34b6c048bda79a574e0e6711fae9cc` 為基礎，合併現行阿肥圖鑑 220 隻怪物及 18 組世界王資料，另保留四組地區掉落。18 組包含僅作其他模式用途、尚未開放一般入場的城堡守護者；這次保存其表格，沒有開放該房間。

來源：

- https://zxc518zxc.github.io/data.js?v=88861f06 ：現行掉落清單。
- https://afei.gg/gamedata.json ：缺少物品的原始定義。
- https://toudhue.github.io/my-web/怪物掉落圖鑑.html ：可核實的公開逐項機率。

## 合併規則

採新增合併，不刪除永夜既有掉落項目與機率。361 種來源物品中，184 種沿用原 ID、60 種沿用既有移植對應、19 種採唯一同名物品；餘下 98 種新增 `afei_drop_` 編號，保留原始能力及既有圖示。既有天堂 W 裝備沒有被替換，原存檔不需搬移。

220 隻對照怪物合併後有 1,601 筆掉落；1,138 筆保留永夜原有機率、238 筆採公開參考機率、225 筆使用永夜 `12 / 合併後掉落種類數` 百分比預設。包含其餘原表，共有 243 張逐項表、1,726 筆。每項獨立判定、每筆一件；未公開數值不可視為阿肥官方機率。材料不再於實際入帳時額外折半，避免圖鑑與實際機率不一致。

預設怪物及對照世界王使用合併後的固定掉落表，避免原有混合裝備規則將指定裝備過濾。明確設定的 GM 原表／自訂／混合模式、數量及抽取時機保持優先；自訂空表不回退至預設。一般世界王恢復物品入帳，金幣與 BOSS 結晶 ×1 仍於整場完成後一次結算。中途離開或死亡不發放未結算獎勵。

四龍保留兩組專屬額外獎勵：高級 80% 隨機 1–8 件、稀有 40% 隨機 1–5 件，兩組均含法書，英雄與傳說限制維持。

`reference-20261029.json` 保存來源雜湊、完整 ID 對應、每筆機率來源及合併前物品／世界資料雜湊與機率表。遊戲圖鑑與結算共用掉落表，顯示補充機率說明。
