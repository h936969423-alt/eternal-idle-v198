# 阿肥非裝備掉落同步（2026-10-20）

來源：https://zxc518zxc.github.io/monsters.html 與該頁載入的 `data.js?v=96a0ad9f`。
參考資料保留完整 216 隻怪物、17 個世界王的非裝備清單與來源雜湊。

- 武器、防具、飾品（包含腰帶及寵物裝備）沿用永夜原有掉落與機率，未替換物品能力或裝備庫。
- 非裝備清單逐隻同步。8 隻怪物的備援掉落清單新增內容；實際機率表新增 45 筆並移除 9 筆不在阿肥清單的非裝備掉落。世界王非裝備獎勵核對一致。
- 部分原本存在於清單的物品未列入優先使用的機率表，這次也補入機率表，確保實際可掉落。
- 阿肥圖鑑及公開 `gamedata.json` 未提供可核實的機率與數量。保留既有同怪同物機率；機率表新項目沿用永夜 12% 備援規則換算：`12 / 合併後不重複掉落種類數`（百分比，分母包含保留的裝備）。每筆一件，這些數值是永夜預設，不能視為阿肥官方機率。
- 沒有機率表的怪物繼續使用既有 12% 整體掉落判定，再從清單等機率選一件。世界王維持原有結算規則；地區額外掉落與 GM 自訂優先順序維持原樣。
- 部署前檢查線上 GM 怪物設定，`definitions` 與 `bossDrops` 均為空，無舊自訂掉落覆蓋此次更新。
