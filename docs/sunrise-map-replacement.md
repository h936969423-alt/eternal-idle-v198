# 日出背景替換

來源：pp771007/idle-lineage-class，固定版本 5f00f4a86389aaa7309c24d7a7c1ab060c47b500（v3.8.34）。

138 個區域對應 88 張原始 JPEG，完整清單見 lib/game/sunrise-maps.json。包括現有一般狩獵地圖、村莊與具對應背景的世界王棲息地。燃柳村以實際村名對應，不沿用內部 town_gludio 的古魯丁名稱。傲慢之塔依來源分組：1 樓、2–10 樓、11–20 樓共用各組背景。林德拜爾的 8 個王房沒有同名原圖，保留原有背景，清單明列 unmatched。

共用 sceneBackground() 優先使用新圖；村莊及戰鬥場景同步套用。保留原本畫面裁切、角色、怪物與攻擊判定。這是靜態背景替換，不新增行走地圖或修改碰撞。

建置從固定來源提交下載，逐一核對 Git blob SHA-1 與 JPEG 1920×1080 尺寸，圖片置於 public/assets/sunrise-maps/ 以不可變雜湊檔名部署。玩家使用本網站圖片，不連線 GitHub 載入。來源缺檔或變更會停止建置。最終輸出再驗證每一張引用圖片存在，避免 R2 素材裁切流程遺失新圖片。

依使用者要求，更新完成提供 GitHub Actions 建置與部署紀錄網址；不以遊戲入口代替。
