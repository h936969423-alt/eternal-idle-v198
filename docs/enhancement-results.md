# 單件強化與結果動畫
沿用現有一般、祝福、一鍵安定、精煉強化規則；不新增金幣費用或修改機率、強化跳級與消耗。
選擇方式後確認消耗與風險，再執行一次伺服器操作；蓄能至少一秒，點擊揭曉後播放成功、維持、消失三種動畫。
動畫只呈現已保存的結果，不參與強化判定。成功顯示實際前後強化值與同件裝備的能力比較；維持保留圖示，消失使用碎裂與灰燼效果。
強化視窗在原裝備 key 被拆分或移除後仍保留，直至玩家選擇繼續、更換裝備或關閉。繼續強化使用結果中的實際裝備 key。
每角色保留遞增序號與最近 32 筆強化收據。相同請求重試回傳原收據；收據移出歷史後，過期序號仍不能再扣卷。
後端收據包含 success/hold/destroyed、前後強化值、卷軸與消耗、原 key 與實際 key，不靠中文通知文字判斷。
舊呼叫方式仍相容；新介面一律使用 UUID、序號及 expectedEn。成功與維持後的重試不重扣卷，破壞後的重試不影響同名其他副本。
支援 reduced-motion；新介面不再將維持或消失顯示為成功通知。
驗證：scripts/test-enhancement-results.cjs，包含交易與重試、實際 UI 階段、三種結果、連點及繼續強化。
