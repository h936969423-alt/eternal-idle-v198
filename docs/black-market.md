# 銀騎士村黑市
潘朵拉提供單抽、十連抽、免費進度與完整獎池查看，不提供世界王抽獎。
保留原有 Lv.41 門檻。每次付費 300,000 金幣，累積 10 次付費後下一次免費；免費抽不累積進度。
十連抽逐次套用免費次數，費用預先顯示並由伺服器重新計算，餘額不足時整筆不執行。
只使用原本 gachaWeight > 0 且未標示 _noGacha、已開放的物品，篩選目前顯示品質為普通、高級、稀有。
三種品質各占 1/3，同品質內每件物品等機率；舊權重只用於獎池資格，不用於抽取權重。
任一品質獎池為空時暫停抽取，不改變其他品質的機率。
每角色保存付費進度、遞增序號與最近 32 筆抽獎收據。請求使用 UUID 和預期序號；重試回傳原收據，不重抽或重扣款。
即使舊收據已移出歷史，過期序號也不得再次扣款。不同分頁的過期請求需要更新狀態。
金幣、物品、進度及收據由既有遊戲 API 的 D1 revision CAS 一併保存。
動畫只展示結果，實際獎品由伺服器產生；斷線時可重試確認同一筆請求。
