# GM 怪物與掉落設定

- `/gm` 的怪物能力與掉落管理支援現有 248 個怪物編號。資料存於 D1 `world_settings` 的 `monsters` 列，透過既有 GM 身分與同源檢查管理。
- 未編輯怪物沿用原有資料與掉落。每次生成複製設定到個體；場上個體保留舊版至死亡，下一次生成套用新值。世界王獎勵按整場生成時複製設定，避免途中更改獎勵。
- GM 可修改等級、AC、最大 HP/MP、HP/MP 回復量與各自間隔、物理傷害範圍、普攻間隔。怪物 MP 與時間狀態儲存於個體。死亡不回復，回復不超出最大值。AC 接命中計算；等級接怪物命中計算。經驗和金幣基礎數值保留。
- 每個怪物最多 8 招魔法，包含原有招式與已支援的攻擊、治療、中毒、暈眩、緩速、沉默、加速。設定傷害／治療範圍、屬性、MP、施放機率、冷卻、HP 條件、狀態數值／秒數。MP 不足、未通過機率或 HP 條件則不施放也不扣款。每招獨立冷卻。原有招式的 MP 未確認，轉入編輯器預設費用為 0，GM 可自行設定。
- 物理傷害接角色減傷，魔法傷害接 MR、元素抗性及魔法減傷。原有特殊招式保留既有特殊效果。特效使用已有素材；未有素材者不補造特效。
- 每項自訂掉落独立判定，機率允許小數 0–100%，數量 1–1000；物品不重複，最多 100 個。100% 必掉、0% 不掉、關閉不掉。娃娃加成按比例：基礎 10% 加成 20% => 12%，封頂 100%。物品未達原活動開放日期時不發放。
- 切換自訂時，公開清單以原本 12% / 清單件數填入初始值；此為本版遷移值，並非原站公布的個別機率。未有公開清單者從空清單開始。
- 普通怪物自訂清單取代原本替代掉落。世界王成員個別掉落與世界王獎勵相互獨立。世界王獎勵可選每隻成員擊殺發一次或整場完成發一次，取代既有世界王整場清單；不在輪詢時重複發放。
- 可複製掉落清單，預覽修改前後，儲存完整操作者與前後設定，保留最近 500 次修改，還原上一版。修訂號採樂觀鎖，阻止其他視窗的舊版設定覆蓋新設定。
- 遊戲同步先完成既有個體的戰鬥，再載入最新編輯設定供往後生成使用；不以新參數重算過去擊殺。
