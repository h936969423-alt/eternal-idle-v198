# 阿肥 NPC 集中銀騎士村（2026-10-29）

基於 GitHub `977da66bfb59fa142d3447d246eab8b424ecc638`，將阿肥公開遊戲資料中的 73 個 NPC 配置集中到銀騎士村。相同主要服務由一位代表承接：預設顯示 22 位（含永夜原有娃娃商人）；另外保留 2 位原站隱藏 NPC 的隱藏狀態。其他村莊不再重複放置 NPC。GM 自建 NPC 亦集中到銀騎士村。

## 資料與對應

- `npc-hub-data.json`：代表 NPC、73 組來源位置對應、商品、原價／永夜價格及公開配方。
- `afei-npc-items.json`：補齊 69 種商店／配方需要的物品，使用原始定義及既有圖示；不替換原有裝備能力。新增物品不進入通用購買及隨機抽取池，須由指定 NPC 或配方取得。
- `npc-hub.ts`：於共用資料載入後套用服務中心，前端、GM、商品與伺服器配方共用同一份實際位置。原始 `gamedata.json` 保留歷史快照，執行時由服務中心資料覆蓋 NPC 位置與補充物品。
- `reference-20261029.json`：原站 NPC、公開配方原文、試煉資料、物品對應與來源雜湊。

來源：`https://afei.gg/gamedata.json`、`https://zxc518zxc.github.io/data.js`、`https://zxc518zxc.github.io/trials.html`；卷軸提煉與妖精選擇屬性的明確數值另核對阿肥公開網頁客戶端。

## 可操作的服務

格林整合雜貨與箭矢、溫諾整合武器、范吉爾整合防具、愛弗特整合布料、巴耶斯整合法書。商品由公開「可購買」清單決定，不把全部高價道具自動上架。已移植裝備沿用永夜價格，原阿肥新增品採原價；箭矢沿用永夜每支 1 金幣的補給規則。

160 筆解析出的公開配方合併去重後，143 筆可實際操作，包含材料加工、裝備製作、職業試煉、解封與寒霜武器兌換。一般配方只用 +0、未穿戴、未鎖定、無詞綴的材料；指定強化配方只用精確 +9，不消耗 +8、+10 或其他不符合的物品。伺服器先驗證全部資格、成本與材料，再扣除及產出；支援多件產出與批量次數。職業試煉保留公開職業、等級條件。50 級迪嘉勒廷試煉缺少已開放的完整配方，沒有額外編造。

碧恩賦予及娃娃卡片兌換／合成維持原功能，服務位置統一銀騎士村；工坊與娃娃畫面的導引一併修正。原倉庫維持永夜既有存取規則。

阿肥大師卷軸提煉每次耗武器／盔甲卷軸各 10 張，1% 成功，成功後兩種祝福卷軸各 50%。失敗使用永夜普通物品均等獎池，明確標示並非原站完整獎池。妖精選屬性需 Lv.30、停止狩獵，首次免費、更換 50 萬；技能頁與 NPC 共用伺服器規則，防止繞過資格或費用。黑市維持永夜既有獎池，依公開門檻需 Lv.41，每次 30 萬。

寒霜販售：台灣時間 10/29 12:30～11/3 12:30；指定 +9 寒霜武器兌換：至 11/4 12:30。過期、未開始或無可核對期間的活動不扣材料。月宮玉兔原有每日限額與配方 ID 保留，未確認新開放期間前暫停兌換。

## 保留說明的服務

血盟、傭兵協力、祈福與原站船票航程仍缺少完整可移植的多人或數值資料。這些代表 NPC 已放入銀騎士村，明確顯示服務狀態，不提供假的扣款按鈕，也不宣稱機制已與原站相同。奧貝勒先提供永夜可用的免費怪物位置查詢與地圖入口；未模擬原站消耗搜索狀的追蹤流程。

## GM 與驗證

舊村莊商店設定會依對應表合併，代表商人的覆寫優先；不會遺失其他來源商人的自訂商品。第一次編輯或重置後，該商店設定整理為銀騎士村的新位置。舊資料不需重置角色。

驗證涵蓋 73 個來源配置、22 位可見代表、143 筆真實製作／兌換、購買後學法書、批量與產量、GM 設定合併、隱藏與改價、鎖定／穿戴／強化／詞綴保護、職業／等級、+9 與期限、提煉與妖精選屬性；另執行 NPC 元件渲染、TypeScript、掉落與四龍回歸及完整建置。本地瀏覽器預覽因連線遭拒未完成操作驗證；元件渲染檢查與伺服器整合測試分別驗證清單及交易行為。
