# 永夜混合掉落

新增的本地成長規則，不宣稱是 3.81 原始伺服器掉率。裝備能力、原始圖檔、強化規則不變。

## 規則與優先順序

- 未自訂的一般怪採混合掉落；已存的 `original` 與 `custom` 規則照舊。GM 在怪物「掉落物」頁可切換三種模式。
- 裝備先判定掉率，再抽分類權重，再從該分類候選裝備等機率選一件。空分類不會轉發其他分類。
- 候選池優先取目前地圖怪物的原有清單；沒有任何可掉分類時，以該地圖固定的分級備用池補足。BOSS 補足英雄／傳說候選；世界王補入一件固定專屬神話候選。指定清單不補入。
- 一般怪依等級限制最高分類；75 級以下不掉傳說成品，一般怪與精英怪不掉神話成品。召喚小怪不觸發此規則。
- 材料、卷軸、法書保留原有判定；混合模式會移除舊表的裝備結果，避免繞過分類限制。GM 額外清單僅補充非裝備掉落。
- 世界王預設採混合掉落；已有 GM 世界王掉落表優先，需勾選混合掉落才啟用新規則。混合裝備與碎片整場完成時只抽一次；原有固定獎勵可維持每隻或通關判定。BOSS 結晶保底保留。

| 怪物等級 | 分類權重 |
| --- | --- |
| 1–29 | 普通 90、高級 10 |
| 30–44 | 普通 20、高級 75、稀有 5 |
| 45–54 | 高級 60、稀有 39、英雄 1 |
| 55–64 | 稀有 90、英雄 10 |
| 65–74 | 稀有 70、英雄 30 |
| 75+ | 稀有 50、英雄 49、傳說 1 |

普通裝備掉率 3%、保底 300 次；精英 8%、保底 80 次，並將最高開放分類權重加倍。一般 BOSS 掉率 100%，英雄 95／傳說 5；世界王掉率 100%，英雄 89／傳說 10.99／神話 0.01。掉落加成只乘第一階段掉率，不放大分類權重。

## 初始裝備分類

GM 單件分類覆寫優先。3.81 裝備按需求等級或基準價分級：70 級／50 萬為傳說、55 級／15 萬為英雄、40 級／3 萬為稀有、15 級／3 千為高級，其餘普通。以下五件是初始神話：風刃短劍、真．冥皇執行劍、紅影雙刀、吉爾塔斯魔杖、吉爾塔斯之劍。分類不增加攻擊力。

## 保底與製作

保底記錄按角色、地圖、怪物或王房隔離，保存於角色檔案，線上／離線共用。連續未獲得裝備累積，取得任一裝備歸零；裝備掉率 0%、空池、召喚怪均不累積。規則或候選裝備變更時重置。保底只保證一件可用裝備，不保證高階。王房通關才累積，未完成不計。每角色最多保留 512 組計數。

55 級以上普通怪有 0.5% 傳說碎片、精英 2%；BOSS 有 100% 傳說碎片及 0.1% 神話碎片；世界王兩種各 100%，各一個，GM 可改。掉落加成適用碎片。

象牙塔塔斯新增製作：傳說裝備需傳說碎片 100、金幣 100 萬、角色 55 級；神話裝備需神話碎片 300、傳說碎片 100、金幣 300 萬、角色 75 級。配方使用當前 GM 分類，只提供有基準價且可用的 3.81 裝備。鎖定材料不消耗，先驗證全部成本再扣除；分類被調整後舊配方立即失效。
