# 手動三重矢回應修正

原流程會等待正在進行的 GET 背景同步（單次最長 30 秒，讀取可重試），再送 POST；確認事件抵達後，三重矢攻擊動畫還可能等待既有普攻／施法動作完成，且箭矢沿用普通攻速的一半等待時間。

本次修改：
- 手動操作中止前端正在等待的背景讀取；讀取不重試、不套用遲到結果，手動 POST 仍僅送一次。POST 不被中止或重試，伺服器現有 revision/CAS 衝突處理保留。
- 同一任務佇列中尚未開始的輪詢，在已有手動操作待處理時略過。
- 點擊技能顯示施放中；成功／失敗後清除，不預造傷害或扣除資源。
- 伺服器確認的手動動作可取代目前未完成的普攻／施法／受擊姿勢，死亡姿勢仍優先。
- 三重矢獨立 90ms 動作（依使用者指定調整），箭矢等待 60ms；保留三個既有命中事件間的 90ms 間隔。手動回放以最早手動事件對齊當下，避免三個事件同時被視為已過期而一口氣播出。

不變更傷害、MP、箭矢消耗、自動戰鬥節奏或伺服器規則。使用者網路往返仍存在，確認前僅顯示處理中。
