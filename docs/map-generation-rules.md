# GM 地圖怪物與生成設定

- 地圖編輯器可搜尋既有與自訂怪物，加入、移除或停用單一種類。這些操作只改該地圖生成池，不刪除怪物能力資料。權重 1–100，出現機率為權重除以啟用項目的權重總和；每張地圖最多 100 種。
- 各地圖可設定 1–6 隻及 0.5–86,400 秒重生基準。預設數量仍為 3 隻；舊版地圖的重生基準統一轉為 5 秒，保留數量與怪物池。變身走速、加速、勇敢、餅乾、疾走、行走加速與裝備移速影響實際等待；日光術及席琳效果各乘 0.8，最低 0.5 秒。新版 GM 改動的基準會套用同一加速規則。村莊不能編輯怪物生成。
- 調整種類、暫停生成或減少數量不重置已在場怪物血量。減少時多餘位置於擊殺後停止補位；增加時產生新增位置。移除所有啟用種類後，既有怪物擊殺完停止狩獵。既有重生倒數保留，新間隔於下一次擊殺使用。
- 開啟原已停用地圖後可重新生成，再手動開始狩獵。
- 自訂怪物最多 200 隻，伺服器驗證 UUID 編號、名稱、既有圖示與範本。初建複製範本能力、經驗與金幣；魔法和掉落從空清單開始。可以透過既有怪物編輯器設定能力、獎勵、魔法與掉落。自訂怪物使用生成時的完整能力快照，避免途中編輯影響既有個體。
- 世界王生成獨立開關、數量與擊殺整場後重生間隔。單一種類王房可設 1–6 隻；四王固定原成員一組。間隔 1–604,800 秒。既有王房及其重生倒數保留，新設定於下一場出生時複製。
- 設定存於 D1 的 `world_settings/map_pools`，使用既有 GM 權限、來源檢查、修訂號樂觀鎖、修改前後預覽、500 次紀錄與還原上一版。

- 狩獵地圖可選「隨機生成」或「定點生成」。既有配置預設定點；各位置可設定場景百分比座標 X 45–88、Y 28–84，間距至少 14%。這是戰鬥場景座標，並非 PC 地圖格座標。隨機生成在保留人物、狀態列與操作區的候選區域抽選，避開存活怪物，並盡量與前次位置不同。
- 位置在伺服器生成時寫入個體並隨事件重播，重新整理不會重新隨機；修改配置不移動存活怪物，新怪與補位使用新設定。定點每個位置的怪物種類仍依原權重選取。世界王維持既有站位規則。掉落的怪物上方提示跟隨死亡個體位置。
