# 大叔天堂特效匯入

來源為使用者提供的大叔天堂懶人包下載頁之四個 RAR。全部 351 個 SPR 已解碼，209 個獨立動畫（含一個原始空白動畫），保留 139 個五職業編號、208 個武器編號／版本與兩套三重矢原檔。

遊戲接入可對應的 74 個現有技能；原本沒有的王族技能等只保留素材，不新增或猜測技能公式。三重矢只啟用 sprite_0923 一套，施放效果使用11764-0、命中效果使用4394-0。每箭傷害、命中、箭矢消耗與單一目標鎖定維持原本計算。

五職業中的中文標籤就是原始改圖內容，不是新增的介面文字。多套衝暈與武器圖樣可於GM目錄預覽；同編號版本以來源路徑產生穩定ID，避免不同版本互相覆蓋。

受擊包原本就是趣味圖片加音效，共5款。GM可選擇其中一款或關閉；音效仍遵守遊戲音效開關及音量，每3秒最多播放一次，不在MISS、寵物或召喚物受擊時播放。

素材以內容雜湊驗證並分片保存在assets/dasu-v1.part00–23，由restore-dasu-effects.py組回ZIP再驗證逐檔SHA256。不依賴外部下載連結，部署不需要安裝SPR轉檔器。完整動畫使用12 FPS播放；原始RAR未附每幀時長，尚未核對PC客戶端list.spr的逐幀延遲。

GM設定由既有GM身分驗證保護；POST檢查同來源、版本號、武器與特效ID，D1以revision比較更新，避免跨視窗覆寫。設定表獨立為combat_effects，不更動角色存檔或傷害資料。
