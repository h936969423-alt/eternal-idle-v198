## 相容性

新增 lw_skill_<來源ID> 與 lw_book_<來源道具ID>。69 個舊技能 ID 建立按職業解析的對照，不刪除 c.skills 或舊法書；同一技能的新舊紀錄去重。不能對應或不符合新來源職業的既有技能仍保留。未學習的舊版技能不再混入新書目。舊法書仍能用於其對應技能；已學、技能快捷設定與裝備授予技能不寫成重複的永久學習紀錄。

被動技能透過統一能力計算生效，重複 ID 不重複加算。前置強化技能須先學基礎技能。舊的限時增益在對應技能改為被動時移除，不與被動雙算。靈氣／範圍普攻為手動開關，自動施法不會每秒把效果反覆關閉。

## 機制與數值界線

名稱、職業、品質、HP/MP 消耗、技能延遲、來源持續時間與學習道具來自來源。六級品質的顏色沿用永夜普通灰白、高級綠、稀有藍、英雄紅、傳說紫、神話金。

不是天堂 W 伺服器的完整複製。來源未公開的完整公式、基礎能力值、升級效果、技能成功率、商店價格與新技能學習等級採明列的永夜規則（資料版本 eternal-lw-skills-v1）。既有可對應學習等級／傷害骰沿用；新技能品質等級門檻 1/10/30/50/60/70，法書價格 2千/1萬/10萬/100萬/500萬/1千萬。前置強化依品質提升基礎效果 15%/25%/40%，合計上限 100%。

主動技能走獨立的資源、冷卻、目標與事件入口，但傷害仍進既有 damageMonster／掉落管線；不是單純展示清單。物理／魔法／治療用既有永夜計算，成功率及缺少的固定值採本版適配；技能視窗說明標出永夜設定。類型包括單體／範圍、三連擊、治療／共用 HP、MP 吸取、增益／靈氣、淨化、控制／減益、吸血、明確開啟的範圍普攻、護盾、反擊與延遲標記。

隊伍技能適配目前自己的角色、存活寵物與召喚物；沒有新增真人血盟、PvP 地圖、真實移動或位移系統。瞬移沿用重新遭遇；束縛適配現有控制判定；偵察呈現目前敵人資料。死亡厄運縮短列出的既有技能冷卻。雙屬性由精靈大師解鎖第二屬性；雙手武器大師解鎖持盾。沒有來源新動畫／音檔的技能沿用既有對應或通用特效與聲音，不宣稱天堂 W 原版 VFX／音訊。

## 防止再出現多目標錯扣血

單體施法先擷取 Encounter，傷害逐次檢查同一物件仍在場且存活；死亡、切換選取或補怪不重定向。普攻仍用原本單刀一次判定；只有玩家明確開啟「君主／特殊攻擊」類技能才會產生帶技能標記的範圍追加傷害。範圍取原目標附近最多 3 個其他既有目標，永不轉移到新出生 UID。狀態事件與傷害特效分開，避免一個命中重播兩次特效。
