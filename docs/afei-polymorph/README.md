## 行為

- 等級段為 0、15、30、45、50、52、55。隨機只抽目前段；Lv55 無已開啟項目時改抽 Lv52。控制戒指在背包或裝備中生效，自選僅允許目前與上一段。
- 依每種變身加入近遠傷、近遠命中、額外傷害／命中、魔傷、額外魔法點數、MP 恢復、AC、MR、ER 與召喚獸命中。額外魔法點數走既有魔法能力欄位，不增加 MP 上限；召喚獸命中僅加入召喚獸命中計算。
- 變身攻速以 `間隔 × (1 - 攻速百分比)` 生效，變身施法基礎間隔為 2000ms；已知加速／勇敢階段繼續相乘。未變身角色維持既有職業施法與攻擊計算。
- 每種 Lv55 解鎖需 6000 萬金幣、BOSS 結晶、賦予武器／盔甲／飾品祝福卷軸各 5 個。使用既有 `new_item_bless_wpn/arm/acc` 道具 ID，不誤用祝福強化卷軸 `scroll_weapon_b/scroll_armor_b`。先檢查全配方、戒指、等級與材料鎖定，再一次扣除。
- 網頁舊解鎖段落仍寫「角色綁定」，但重點段落明載自 10/11 起改成帳號共用；採用較新的帳號共用規則。合併所有角色既有紀錄至存檔 `polyUnlocked`，換角及重新登入後保留。
- 舊五種專屬 ID `morph_42..46` 依順序轉移到新的紅死騎、焚焰死騎、海露拜、宙斯、依詩蒂。保留解鎖權益與剩餘變身時間，不重新收費；外觀使用新名稱的原始圖片，不挪用舊造型。
- 卷軸維持永夜 1800 秒，自動續用維持狩獵中觸發。過期的跨段自選偏好退回當前可用隨機池。
