# 人物／變身攻擊與施法特效同步

基準：main 1df6eb22de1b375485d39dce1d327e40ca73634b。

## 修正

- 本機揮刀與手動／自動施法起手立即提交第一張動作影格；125ms 計時器只負責後續影格，不再延遲起手。
- 自動施法動作使用特效的 performance.now 顯示時間；過期歷史不重新播放施法。
- 施法打斷尚未抵達接觸影格的揮刀時保留一次攻擊；已有接觸的揮刀不補播。普通攻擊的 100ms 累積計時保持原狀。
- 非飛行攻擊魔法在施法起手時先播放僅供顯示的特效；伺服器確認的 HP／傷害數字仍於特效 hitFrame 才顯示。遲到封包的動作、特效及命中一起採用新的起播時間。
- 手動預覽的確認結果不重播特效；AOE 每個目標保留自己的特效。普通單體攻擊、武器觸發、寵物、娃娃、召喚與飛行投射物維持各自時序。
- 修正魔法 renderer 測試以執行四龍更新後新增的內層 StandardMagicEffect，避免只測到外層元件。
