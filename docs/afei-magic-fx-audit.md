## 接下來的驗證門檻

1. 依技能 ID → 技能名稱 → 特效名稱核對；不得以名稱相似就直接替換傷害技能。
2. 確認永夜本身的相對資產路徑全部可載入、沒有 404。
3. 用 Safari 驗證方向、目標座標、影格大小、音效同步；技能傷害與 MP 由既有伺服器判定。
4. 若要新增來源影格，先確認可使用的授權或取得權利人許可。

本次效能調整：`app/magic-preload.ts` 對已學會的攻擊魔法優先預載完整動畫（總上限 100 張初始載入），其餘技能仍僅預載前兩幀；實際施法時仍補預載完整幀。此為渲染優化，不調整伺服器戰鬥數值。
